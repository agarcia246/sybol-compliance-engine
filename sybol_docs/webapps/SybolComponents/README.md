# SybolComponents

Librería de componentes React compartidos entre las webApps del proyecto Sybol.

## Componentes

| Componente | Descripción |
|---|---|
| `Footer` | Pie de página estándar con branding Sybol |
| `SybolButton` | Botón con variantes de estilo de la plataforma |

## Arquitectura

→ [architecture/components-overview.md](architecture/components-overview.md)

## Uso

```js
import Footer from '../SybolComponents/Footer';
import SybolButton from '../SybolComponents/SybolButton';
```
