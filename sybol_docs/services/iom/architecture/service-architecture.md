# iom — Identity Object Manager Architecture

## Propósito

> ⚠️ Servicio en fase de diseño/desarrollo inicial.

Gestión de objetos de identidad dentro de la plataforma Sybol multi-tenant. Previsto para manejar el ciclo de vida de objetos DID y credenciales relacionadas con identidad.

## Estado actual

El handler actual es un stub Lambda que devuelve `200 OK`.
